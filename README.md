# Bee Indsutry (NeoForge 1.21.1)

A Minecraft mod focused on **industrial beekeeping** and progression systems.
This repo targets **NeoForge 1.21.1**.

## Highlights
- Custom bees & progression-oriented mechanics
- Structured codebase designed to scale with more content
- Focus on performance + maintainability

## Techo / Tools
- Java
- NeoForge (Minecraft 1.21.1)
- Gradle build

## Build / Run (dev)
> Exact steps may vary depending on your mappings / setup.
```bash
./gradlew build
```
