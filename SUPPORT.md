# Support

**Before opening an issue:**
- Update to the latest Bee Industry release for your Minecraft / NeoForge.
- Reproduce with only Bee Industry + required libs to rule out mod conflicts.
- Gather `latest.log` (and crash report if applicable).

**When filing a bug:**
- Provide exact versions (Minecraft, NeoForge, Bee Industry, Java, OS).
- Include minimal reproduction steps.
- Attach `latest.log` (drag & drop) and crash report (if any).
- Include your mod list or Modrinth/Curse profile.

**Balance/Feature:**
- Explain the player value and progression impact.
- Provide concrete numbers or examples if possible.

**Discord:**
- Quick questions and early feedback. Please still open issues for actionable bugs.
